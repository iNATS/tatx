# تاتكس - البوابات الإلكترونية

## البوابات المتاحة

### 1. بوابة المشرف الرئيسي (SuperAdmin Portal)
**المنفذ:** `http://localhost:3001`

لوحة التحكم الرئيسية لإدارة تطبيق تاتكس بالكامل.

**المميزات:**
- 📊 لوحة تحكم مع إحصائيات شاملة
- 🏪 إدارة المتاجر والبائعين
- 📦 متابعة الطلبات
- 👥 إدارة العملاء
- 💰 التقارير المالية
- 📈 التحليلات والإحصائيات
- ⚙️ إعدادات النظام

### 2. بوابة البائع (Vendor Portal)
**المنفذ:** `http://localhost:3002`

لوحة تحكم البائعين لإدارة متاجرهم وطلباتهم.

**المميزات:**
- 📊 لوحة تحكم مع مبيعات اليوم
- 📦 إدارة الطلبات (جديد، قيد التحضير، جاهز، مكتمل)
- 🍔 إدارة المنتجات
- 💰 المحفظة والأرباح
- ⚙️ إعدادات المتجر
- 🔔 إشعارات فورية

## التقنيات المستخدمة

- **React 18** - واجهة المستخدم
- **Vite** - أداة البناء والتطوير
- **Tailwind CSS** - التنسيق
- **Lucide React** - الأيقونات
- **shadcn/ui** - مكونات عربية (RTL)

## التشغيل

### بوابة المشرف الرئيسي
```bash
cd web-portals/superadmin
npm install
npm run dev
```

### بوابة البائع
```bash
cd web-portals/vendor
npm install
npm run dev
```

## التصميم

- **RTL Support**: دعم كامل للغة العربية (من اليمين لليسار)
- **Responsive**: تصميم متجاوب مع جميع الأجهزة
- **shadcn Components**: مكونات عربية مستوحاة من shadcn/ui
- **Colors**: ألوان مخصصة لكل بوابة (وردي للمشرف، أخضر للبائع)
