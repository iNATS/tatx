# Tatx Flutter App

نسخة Flutter أولية من تطبيق `Tatx` مبنية باستخدام:

- `Flutter`
- `Material 3`
- اتجاه `RTL`
- خط `Cairo`

المجلد يحتوي على:

- شاشة رئيسية
- قائمة مطاعم
- صفحة مطعم مع مجموعات وأصناف
- سوق الجملة
- الحساب
- سلة أساسية

لتشغيل المشروع بعد توفر Flutter محليًا:

```bash
cd Tatx-flutter-app
flutter pub get
flutter run
```

ملاحظة:
هذه النسخة هي قاعدة Flutter جديدة تحمل نفس روح التطبيق الحالي وليست نقلًا 1:1 لكل شاشة React Native بعد.
